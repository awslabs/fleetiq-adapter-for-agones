## Go Version (experimental)

This is an experimental rewrite of the pubsub application in Go. It is **not**
the supported implementation and is not built or deployed by the install
guides.

The supported pubsub application is the Python version in
[`pubsub/app`](../app). Use that one for deployments. This Go version is kept
for reference and future evaluation only; do not depend on it in production
until it is promoted to the supported path.
